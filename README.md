Blog List — Full-Stack Web Application

A full-stack blog management application built with React and a RESTful backend. The application allows authenticated users to log in, browse blog posts, create new posts, and interact with blog content through a modern and responsive interface.

The project demonstrates practical experience in frontend development, authentication, API integration, state management, and automated testing. It also includes component and integration tests to ensure application reliability and maintainability.

Technologies

- Frontend: React, JavaScript, Vite, material uiu
- Testing: Vitest, React Testing Library
- Authentication: JWT
- API: RESTful API
- Code Quality: ESLint

Key Features
- User authentication with JWT
- Persistent login sessions
- Blog listing and detailed blog views
- Creation and management of blog posts
- Integration with a RESTful backend API
- Client-side state management
- Component and integration testing
- Modern and responsive user interface

This project was developed as part of the Full Stack Open curriculum from the University of Helsinki and showcases hands-on experience building and testing modern web applications with React.
